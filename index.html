Flutter Deps Watch

باكدجات مشروعك، بالبلدي.

حط لينك أي repo Flutter على GitHub. الصفحة بتقرا pubspec.yaml و pubspec.lock، وتسأل pub.dev عن كل باكدج، وتقولك إيه الآمن تحدّثه دلوقتي وإيه اللي محتاج تقعد معاه. كله بيحصل في المتصفح بتاعك، مفيش server.

الـ repo فيه أكتر من مشروع. اختار واحد:

ترتيب التحديث

كل مجموعة PR لوحدها، بالترتيب ده. الباكدجات اللي من نفس الـ repo (زي firebase_*) بتتحرك مع بعض دايمًا.

كل الباكدجات

البيانات من pub.dev و GitHub و Flutter releases، مباشرة من المتصفح. المصدر على GitHub

الإعدادات

محتاجه بس للـ repos الـ private، أو لو GitHub وقفك بعد 60 طلب في الساعة. اعمل fine-grained token صلاحيته Contents: Read-only بس. الـ token بيروح لـ api.github.com وبس.

شرح التحديث بالـ AI

زرار «اشرحلي التحديث ده» على كل باكدج بيكتبلك بالمصري إيه اللي اتغيّر ومعناه إيه لكودك وتعمل إيه. بيشتغل بمفتاح API بتاعك إنت: المفتاح بيروح لمزوّد الـ AI وبس، وكل شرح بيبعتله الـ changelog وسطور من الفايلات اللي بتستخدم الباكدج.
